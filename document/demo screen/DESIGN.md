# StoryFlow Studio · Design

ขอบเขตของเอกสารนี้คือภาพเดโมหน้าจอแบบ Operate อ้างอิง [Concept v2](../../StoryFlow-Game-Studio-Concept.md) และ [ภาพ Workflow](StoryFlow-Workflow.png)

## โครงหน้าจอ

- คงเมนูซ้ายและชื่อโปรเจกต์ในทุกหน้า เรียง Project → Story Graph → Rules & Schedule → Playtest → Validate → Export
- ให้กราฟอยู่กลางหน้าและ Inspector อยู่ขวา แสดงชื่อฉากและทางเลือกของโหนดที่เลือกทันที
- Playtest แยกภาพพรีวิวจากตัวแปรและ Trace แสดงค่าจริงกับเกณฑ์ข้างกัน เช่น 19 จาก 20
- Validate แยก Error กับ Warning ด้วยข้อความและไอคอน และมีทางกลับไปยังโหนดต้นเหตุ เปิด Export ได้หลังแก้ Error
- Export แสดงพาธปลายทาง สถานะ manifest และผลการส่งออก ให้ผู้ใช้เปิดเกมใน Ren’Py SDK ต่อเอง

## กติกาภาพ

- พื้นหลัง `#131922` แผง `#202938` ข้อความหลัก `#F2F5F7` ข้อความรอง `#B9C5D3` และเส้นแบ่ง `#526174`
- ใช้ `#58D4B4` กับปุ่มหลัก โหนดที่เลือก และ focus ring ใช้ข้อความสีเข้มบนปุ่มสีเขียว
- ใช้ฟอนต์ UI ที่รองรับไทยและอังกฤษ เช่น Noto Sans Thai ใช้ monospace กับพาธและ Trace
- ใช้ระยะ 8, 12, 16 และ 24 px จัดฟอร์มชิดซ้าย ใช้เส้นขอบบางและพื้นทึบ ภาพสื่ออยู่ใน Scene Preview
- คง focus ที่เห็นชัด และระบุสถานะด้วยป้ายข้อความร่วมกับสี สำหรับจอแคบให้เปิด Inspector แยกจากกราฟ

## วิธีอ่านภาพ

ภาพแสดงตัวอย่างหกหน้าจอในลำดับเดียวกัน หน้า Validate และ Export เป็นคนละสถานะ ให้ถือว่าผู้ใช้แก้ Error ก่อนเปิด Export ข้อความ ค่า และจำนวนรายการในภาพเป็นตัวอย่างประกอบ UI ส่วนกติกาและค่าตรวจรับจริงให้ยึด Concept และ fixture ของ Summer House
